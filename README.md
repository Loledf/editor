# Исправленный редактор

Распакуйте архив и откройте index.html в браузере. Файлы index.html, style.css и script.js должны находиться в одной папке.

## Структура
- index.html — разметка редактора.
- style.css — стили и встроенные шрифты.
- script.js — библиотеки экспорта, логика редактора, дополнительные панели и обработчик буфера обмена (разделы идут в порядке исходного файла).

## Изменения
- Убраны отдельные flow-root-контексты у абзацев и заголовков; служебные декорации не перехватывают мышь.
- Пересчёт страниц откладывается при выделении текста, чтобы не менять DOM под выделением.
- Копирование и вырезание передают text/plain и text/html. Сохраняются абзацы, пустые строки и табуляция между ячейками; исключаются служебные элементы пагинации.
- Ctrl+A / Cmd+A внутри редактируемого поля выделяет содержимое этого поля, а не интерфейс.
- Сохранены встроенные библиотеки и шрифты: новые внешние зависимости не добавлены.

## Проверка
Проверены синтаксис JavaScript, загрузка в Chromium без ошибок, выделение всего документа и содержимое события copy для заголовка, абзацев, пустой строки, служебного разрыва и таблицы. Проверка реального системного буфера и визуальная проверка в Firefox/Safari не выполнялись.
